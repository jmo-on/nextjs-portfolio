# Lunar textures

Credit: NASA's Scientific Visualization Studio.
Source: CGI Moon Kit, https://svs.gsfc.nasa.gov/4720/.

- moon-color.jpg: lroc_color_2k.jpg (2025 LROC color mosaic, 2048 × 1024).
- moon-height.jpg: ldem_3_8bit.jpg (LOLA elevation preview, 1024 × 512).

The images are stored unchanged and served locally. Color is interpreted as sRGB;
elevation is linear data, used for subtle bump and displacement. These are visual
assets, not scientific measurements for use in this application.
